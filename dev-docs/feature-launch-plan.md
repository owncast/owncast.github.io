## What is it?

A feature launch plan is a roadmap for launching a new feature in an existing product to make sure users have a seamless experience with new features.

The plan outlines the strategies teams will use before, during, and after making the feature available to your users.

## Feature launch checklist

### Before release

- [ ] Create test plan containing actionable tasks (e.g. Set a viewer as a moderator in Admin page)
- [ ] 3 weeks: Add a coming soon message to the news section to recruit beta testers to test the feature and gather feedback
- [ ] … anything else needed to facilitate the test
- [ ] [if applicable] Create a step-by-step user guide (with video tutorial) on how the feature works to publish on Owncast documentation

### After release

- [ ] Write release notes here
- [ ] Publish user guide on Owncast documentation
- [ ] Post new feature launch messages on fediverse and/or social media platforms:On Owncast (i.e. In-app News / newsletter)Subreddit (i.e. r/selfhosted)Dev.toOwncast rocket.chat… feel free to add more
