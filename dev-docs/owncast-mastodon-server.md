The Owncast Mastodon server is a server just for Owncast. It is hosted and managed by Fedihost.

I wish we weren't using Mastodon, but it is the only hosted and managed option the hosting services provide, so that's what we're stuck with.

If you need access because you are going to take part in Owncast's social media presence, talk to Gabe.

## Followers

We used to have over 5,000 followers on the Fediverse, but we lost them when we moved to this new server, so we are starting over.
